Hospital Reservas - Admin

¿Qué puede hacer el administrador?

  • CRUD de citas: GET/POST/PUT/DELETE /api/v1/citas/**
  • CRUD de historiales médicos: GET/POST/PUT/DELETE /api/v1/historiales/**
  • CRUD de pacientes: GET/POST/PUT/DELETE /api/v1/pacientes/**
  • CRUD de pagos: GET/POST/PUT/DELETE /api/v1/pagos/**
  • CRUD de servicios: GET/POST/PUT/DELETE /api/v1/servicios/**
  • CRUD de médicos: GET/POST/PUT/DELETE /api/v1/medicos/**
  • CRUD de horarios: GET/POST/PUT/DELETE /api/v1/horarios/**
  • CRUD de notificaciones: GET/POST/PUT/DELETE /api/v1/notificaciones/**

Ayuda rápida

  • Buscar: Usa el campo de búsqueda para filtrar médicos o pacientes.
  • Agregar: Haz clic en "Agregar" para crear un nuevo registro.
  • Editar: Haz clic en "Editar" para modificar datos existentes.
  • Eliminar: Haz clic en "Eliminar" para borrar un registro (¡cuidado, es irreversible!).
